Tarif profile MikroTikNominal bulanan memakai tarif profile sebagai default dan dapat dicustom per pelanggan

Contoh: profile 30Hari diisi 40000, maka nominal awal pelanggan adalah Rp40.000. Nominal tiap pelanggan tetap dapat dicustom dari menu Tagihan.

Muat profile MikroTik untuk mengatur nominal bulanan.

Contoh Jika jatuh tempo hari ini dan jeda diatur 3 hari, akun yang belum lunas baru diisolir tiga hari lagi. Isi 0 untuk isolir tepat saat jatuh tempo.
