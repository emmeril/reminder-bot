Pengaturan aplikasi

Identitas aplikasiAtur nama, ikon, dan informasi yang tampil di aplikasi.

Ikon aplikasi

Pilih gambar PNG, JPG, atau WebP (maksimal 3 MB). Ikon akan diperkecil menjadi 256 × 256 piksel agar sesuai untuk menu aplikasi dan ikon tab browser.

Zona waktu menentukan tanggal dan jam yang digunakan untuk pengingat serta laporan.

Harga paket WiFiHarga awal mengikuti profil MikroTik. Harga setiap pelanggan tetap bisa diubah.

Contoh: jika profil 30Hari diberi harga Rp40.000, pelanggan baru yang memakai profil ini akan mendapat harga awal Rp40.000. Harga khusus pelanggan dapat diubah di menu Pelanggan, tab Tagihan.

Belum ada daftar profil. Tekan Muat daftar profil untuk menampilkan paket dari MikroTik.

Jadwal backupAtur waktu pencadangan MikroTik dan database aplikasi secara terpisah.
Backup MikroTik
Backup database aplikasi

Salinan database tetap disimpan di server setiap hari meskipun pengiriman Telegram dimatikan atau gagal.

Backup database berisi data pelanggan dan informasi akun. Kirim hanya ke Telegram admin yang tepercaya. Tujuan Telegram diatur di server melalui TELEGRAM_CHAT_IDS, bukan melalui daftar nomor admin WhatsApp. Tombol kirim manual tetap mengirim keduanya, meskipun backup terjadwal dimatikan.

Pengiriman pesan WhatsAppAtur jarak waktu antar pesan dan nomor WhatsApp penerima notifikasi admin.

Aplikasi memilih jeda secara acak di antara kedua nilai. Contoh: 2 dan 5 berarti jeda 2–5 detik antar pesan.

Penerima admin

Nomor WhatsApp admin yang menerima pemberitahuan saat opsi notifikasi admin di tab Otomasi diaktifkan.

Tulis satu nomor per baris, diawali 62 (contoh: 628123456789). Ini untuk pesan WhatsApp, bukan backup Telegram. Tekan Simpan Pengaturan untuk menyimpan.

Masa tenggang paket WiFiAtur berapa hari akun tetap aktif setelah masa berlaku paket berakhir.
Contoh Jika paket WiFi berakhir hari ini dan diisi 3 hari, akun dijadwalkan nonaktif tiga hari kemudian. Isi 0 agar akun nonaktif saat masa aktif paket habis.
Isi pesan otomatisUbah pesan pembelian, pengingat paket, informasi akun, dan gangguan perangkat WiFi.

Teks dalam tanda kurung kurawal seperti {{name}} dan {{activeUntil}} akan diganti dengan data pelanggan saat pesan dikirim. Jangan mengubah nama kode tersebut.

Pengingat dan notifikasi otomatisCentang fungsi yang ingin dijalankan. Notifikasi admin dikirim ke nomor di tab Pengiriman.
